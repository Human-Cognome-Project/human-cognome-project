**Purpose:** the shared contract so Planner (temporality / time-step) and Silas (diffusion / kernel) can build the two halves against each other and just *run* it — the build is the theory (P, 2026-08-29). ## Particle record (the shared struct — minimum both halves need)

| field | type | meaning | written by | read by |
|-------|------|---------|-----------|---------|
| `amp[16]` | float, sum-normalized | the superposition over the 16 bit-codes. chaos = uniform 1/16; resolved = ~one-hot. **THE field state.** | **kernel** | both |
| `det` | float ∈ [0,1] | determination-density = 1 − H(amp)/H_max (normalized entropy). 0 = chaos, 1 = absolute identity. | **time-step** | both |
| `code` | int ∈ [0,15] | argmax(amp) — the identity-so-far (meaningful only at high `det`). | **time-step** | both |
| `compliance` | float ∈ [0,1] | the coupling field. compliance = f(`det`); stiffness = 1 − compliance. **A resolved region is stiff.** | **time-step** | **kernel** |
| `tau` | float | LOCAL proper-time = ripple-depth (fronts passed through this particle). | **time-step** | both |

Position is implicit (lattice index). Global (not per-particle): `step` (int), `T` (annealing temperature, **floor > 0 — never zero, so the search never terminates**), `complexity` (the observable-arrow metric).

## Per-tick contract — two phases, one shared field, no cross-writes

```
each tick:
  # ── PHASE A · KERNEL (Silas) — propagate determination (the front) ──
  for each particle p:
      c_local = c0 * g(compliance[p], κ)        # κ=0 → g≡1 (flat c); κ>0 → g decreasing (fronts slow in stiff/resolved regions)
      amp[p] ← diffuse(amp[p], amp[neighbours], rate=c_local, temp=T)
  # ── PHASE B · TIME-STEP (Planner) — readout, advance time, schedule ──
  for each particle p:
      det[p], code[p] ← readout(amp[p])         # resolution-depth + dominant code
      compliance[p]   ← f(det[p])               # stiffness rises with resolution → feeds NEXT tick's kernel
      if det[p] − det_prev[p] > front_threshold: tau[p] += 1   # a front arrived → local proper-time ticks
  T ← anneal(T, floor=T_floor)                  # asymptotic: approaches T_floor>0, never 0
  complexity ← measure(field);  step += 1
```

## The seam (why this is the whole coupling)

Exactly two fields cross the boundary, one each way, one tick apart — so there are **no races** and the division is total:

- **`amp` : kernel → time-step.** The kernel evolves the superposition; the time-step only *reads* it to derive `det`/`code` and detect front-arrival. (mass = resolved / light = resolving: `amp` in motion = light; `amp` frozen high-`det` = mass.)
- **`compliance` : time-step → kernel.** The time-step writes stiffness from `det`; the kernel reads it to set **local c**. This is the c-coupling Silas named — and it is the **one knob**: `g(compliance, κ)` with κ=0 (flat c → flat cosmos) or κ>0 (fronts slow in resolved matter → the cone bends → **mass curves the field → gravity falls out on its own**). We don't pick κ; we run both and watch which one can't *not* bend.

Invariant: `amp` written ONLY by the kernel; `det`/`code`/`compliance`/`tau` written ONLY by the time-step. Nothing else cross-writes.
