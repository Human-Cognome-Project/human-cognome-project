## 4. ONE ingestion routine — and the engine ingests EVERYTHING (P 1372 + 1377)
**The engine receives the FULL FILE. All the data. Structure and everything. Without exception** (P 1377). No cleaning, no extraction, no pre-parsing, no stripping of format "crap" — a PDF goes in whole (binary streams, xref, all of it), because format-ness is content: with 50/300 instances, **PDF emerges as a frame over the content**. File formats separate out through commonalities; they are never told apart up front. "Fixing" the data — selecting what the engine sees, in EITHER direction (stripping file structure OR stripping db information) — is the named error. STOP condition: any code of ours that decides what matters before the engine sees it.
The routine is a single repeatable mechanical ROUTINE, not per-artifact curation — the npz zoo dies. npz/state files are at most the routine's **transient cache, regenerated, never authored beside the db**. **Corrected spec (planner 1379, after P 1377): NOT "db query → engine arrays" — a query that selects columns is a pre-assembler in plumbing clothes. The routine hands the engine the FULL FILE, byte-complete; P's encodings ride in because they're IN the data; formats condense into emergent frames at corpus mass.** ONE seamed routine serves both halves (planner leads v0; kernel reads join it — not two routines). Documents enter through P's load path into the dbs; the engine receives everything, whole.
**Why pure byte streams, beyond full commonality (P, 2026-09-01, ~msg 1454): SECURITY IS STRUCTURAL.** Any system that relies on outside data handling is as vulnerable as the handler — a parser at the door imports the parser's whole attack surface. With no handler, hostile matter has nothing to exploit: the system can take an exe or even a viral packet the same way as a novel — **nothing directly runs; it is pulled apart for analysis** by the same condensation physics. Malice becomes legible as structure without ever being granted a code path. The door's only primitive is read-bytes+hash.

## 6. Temporality artifacts (P 1347–1353; planner-1374 fixes folded)
- **Checkpoint = first-class** (field state + arch/fp/seed metadata), any point; enter/adjust/run-forward.
- **Event ledger, TWO classes: EVIDENCED / HYPOTHESIZED** (one vocab set — supersedes stated/postulated). **Events key to OBSERVED TIME (horizon stamps), never sim-tick** — sim-tick is derived at run time by the runner mapping observed-time anchors to fold-in points (a sim-tick key would bake in a global clock; no universal now).
- Mapping mode = boundary-pinned intervals (past event's telos = its next stated event), block-relaxed on GPU; pins localize recompute. Non-convergent interval = **the discovery flag**: "something like this must happen in this interval, not yet evidenced" — residual gives the candidate's shape+placement.
- **HYPOTHESIZED never PINS the settle** (points outward at the archive only — else self-confirming). Confirm→swap to EVIDENCED, taint clears; contradict→re-open. **Adjustments are themselves dated ledger events, never in-place edits** (replayability). Exact replay is per-arch/per-precision; replays gate on the exact-integer instruments.

## 6b. Future constraint — hold, don't build (P 1433)
Single source today (us, one hcp-db); the back end will be **massively networked: real-time asynchronous coordination of DERIVED connections.** Nothing may bake in single-node assumptions. **ADDRESSING RECONCILES BY METHOD, NOT BY PARTITION (P 1435, major correction — struck my node-scoped-ranges idea): every node computes a token's address the SAME deterministic way from the data itself → same thing = same address everywhere → independent derivation of the same connection produces the IDENTICAL entry → merge is UNION, not conflict resolution. Determinism is the coordination protocol.** Also aligned: observed-time ledger (no global clock = the distributed requirement), origin-marking (node-of-origin is metadata beside the address, never part of it; foreign derived connections land HYPOTHESIZED until locally confirmed), small-travel (derived connections + latent shards, not corpora). Same law as the substrate: selection by use, names included.
